# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you discover a security vulnerability in aeoncord, please report it privately to:

**contact.mrf0rtuna4@gmail.com**

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The affected version
- The potential impact
- Any suggested mitigation, if available

Please allow reasonable time for the vulnerability to be investigated and addressed before publicly disclosing it.
